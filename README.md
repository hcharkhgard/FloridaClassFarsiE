# Florida Class E Practice (English + Farsi)

Six 50-question mock tests for the Florida Class E Knowledge Exam, in English and Farsi (Persian), plus a Farsi self-study guide. Built with Hillsborough County applicants in mind.

- 300 questions, no repeats between tests. Answer choices are shuffled on every attempt.
- The correct answers stay hidden until you submit.
- The results screen shows your score, the number right and wrong, and PASS (40 or more of 50) or FAIL.
- Every missed question is listed with the English and Farsi text, your answer, the correct answer, and a Farsi explanation.
- An "English only" mode hides the Farsi while you test. The real exam has been English only since Feb 6, 2026.
- The Farsi study guide has 22 sections, a table of numbers to memorize, and an English–Farsi glossary.
- It works on phones and tablets. Progress is saved in the browser on that device.

## Publish on GitHub Pages

1. Create a new repository and upload `index.html`, `.nojekyll` and this `README.md`.
2. Open **Settings → Pages** and set **Source** to "Deploy from a branch". Choose the `main` branch and the `/ (root)` folder, then save.
3. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
4. On an iPhone, open the link in Safari and tap **Share → Add to Home Screen** to use it like an app.

The app is a single file with no build step. It needs an internet connection only to load its fonts (Google Fonts).

## Sources and accuracy

The answers are based on the Florida Driver License Handbook, FLHSMV web pages, the current Florida Statutes (chapters 316, 318 and 322), and Hillsborough County Tax Collector notices. Each question links to its source in the review screen, and the full list is in the app's **Sources** tab. Everything was checked by independent reviewers on Sep 27, 2026. Where the handbook text and a newer law disagree, the app follows the law.

These are practice questions written for study. They are not FLHSMV's real exam questions, which are not published. Laws change, so check the current handbook at flhsmv.gov before your exam.
